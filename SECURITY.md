# Security Policy

## Reporting a Vulnerability

Please don't open a public issue for a security problem.

Report it privately instead: on this repository's **Security** tab, choose **Report a vulnerability**. Only the maintainers can see the report.

Include what you found, the affected package and version, and the steps to reproduce it. You'll get a reply within 7 days. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

## Supported Versions

Fixes go into the latest release of each package.
